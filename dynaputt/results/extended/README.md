# Extended studies

Generated by `python run_extended.py` from 100 seeds (1000-1099). These runs are
separate from the primary five seeds in `results/` and must not be pooled with
them. Read `summary.md` first.

- `runs.csv`: one row per run for the budget, stream, and initial-value studies on
  `easy` and `wall_gate` (350 episodes).
- `summary.csv`: per-condition summary of `runs.csv`.
- `route_length_runs.csv` and `route_length_summary.csv`: the same for the
  `ladder_1` to `ladder_4` courses (800 episodes).
- `summary.md`: all tables, with paired bootstrap intervals.

The initial-value and route-length studies were designed after seeing the first
results, so they are exploratory. The three initial values were chosen by
reasoning about the return range, not tuned.
