Coursework for COMP 765.

## Assignment 1

`assignment1/TeachingCartpole` contains the supplied simulator, completed LQR
and hybrid swing-up controllers, a deterministic experiment harness, recorded
results, DoubleCartpole and learned world-model bonus experiments, and the
assignment report.

See [assignment1/README.md](assignment1/README.md) for reproduction commands.

`putt_world/` contains the COMP 765 course project: a small LeWorldModel that learns
continuous mini-golf from pixels, with experiments, a browser demo, station materials,
and the report. See [putt_world/README.md](putt_world/README.md).

`dynaputt/` contains the project's earlier tabular Dyna phase. See
